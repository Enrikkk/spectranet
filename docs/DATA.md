## Download recipe

```bash
mkdir -p data && cd data

# 1. Public NS ν=10⁻⁵ at 64²  (~150 MB)
wget https://huggingface.co/datasets/zongyi-li/fourier_neural_operator/resolve/main/NavierStokes_V1e-5_N1200_T20.mat

# 2. Public NS ν=10⁻⁴ and ν=10⁻³ (extended FNO suite — see linked FNO repo for the canonical mirror).

# 3. PDEBench Shallow Water + Diffusion-Reaction
#    Download from https://github.com/pdebench/PDEBench  (each file is several GB).

# 4. The Well — Active Matter
#    Download from https://github.com/PolymathicAI/the_well .
```

## In-house 128² provenance

The native-128² Navier–Stokes dataset is hosted on Zenodo under anonymous metadata; see [`ARTIFACTS.md`](ARTIFACTS.md) for the DOI.  Once downloaded, place the file at `data/ns_v1e5_128_N1200_T20.mat` and the trainer / eval scripts will pick it up automatically.

The dataset was generated by **us** following the same pseudo-spectral solver protocol used by Li et al. (2020) for the public 64² release:

- 2D vorticity equation in stream-function form on a periodic [0, 1]²;
- Crank–Nicolson on the linear (viscous) part, explicit forward Euler on the nonlinear advection;
- 2/3 dealiasing on the convolution sum;
- Gaussian-random-field initial conditions with Matérn-like spectrum `(4π²k² + τ²)⁻ᵅ`, defaults α=2.5, τ=7.0;
- Forcing `f = 0.1·(sin 2π(x+y) + cos 2π(x+y))`.

The generator is `scripts/generate_ns_128.py`.  Reproduce the shipped file end-to-end with:

```bash
python scripts/generate_ns_128.py --out ./data/ns_v1e5_128_N1200_T20.mat
# ~6 hours on a single H100; produces a 1.5 GB scipy v5 .mat file
```

The seed is fixed (`--seed 0`), so this regenerates the bit-identical shipped file.

## Format conventions

All datasets are loaded by `spectranet.data.MatReader`, which transparently handles both scipy v5 (small files) and HDF5 v7.3 (large files) via `h5py`.  The contract is a single field `u` of shape `(N, S, S, T)` in `(N_traj, height, width, time)` order, real-valued, fp32.  Cross-viscosity files use HDF5 v7.3 with axes reversed `(T, S, S, N)`; `eval_cross_viscosity.py` auto-detects and transposes.
