# Reproducing every paper number

Each paper claim, table, and figure is anchored to one or more concrete commands here.  All commands assume you are at the `release/` root and have run `pip install -e .` plus downloaded the public datasets per [`DATA.md`](DATA.md).

## Quick verification (no GPU, no dataset)

```bash
pytest tests/                      # 69 tests, ~2 seconds
```

Confirms: spectranet package imports cleanly, canonical config gives **2,040,705** parameters, decorated config gives **2,124,166**, the 128² resolution-invariance forward pass works, and no anonymity-leaking tokens appear in any release file.

## Headline result (paper §7, Table 2 row 1)

```bash
# canonical reproduction — 100 min on a single H100
python scripts/train_spectranet.py \
       --config configs/spectranet_ns_v1e5.yaml \
       --data_root ./data
# expected: best_test_l2 ≈ 0.0822  (multi-seed σ ≈ 0.0001)
```

Or skip retraining and run an inference-only sanity check against the shipped checkpoint:

```bash
python scripts/eval_long_horizon.py \
       --ckpt checkpoints/spectranet_ns_v1e5_canonical_best.pt \
       --data_path ./data/NavierStokes_V1e-5_N1200_T20.mat \
       --T_max 100 --T_eval 10
# expected sanity: full-rollout L² ≈ 0.0822 (matches headline)
```

## Long-horizon stability (paper §7.3, Figure 3)

The headline finding: **FNO blows up between T=20 and T=50 on every test trajectory; SpectraNet stays bounded for 100 steps**.

```bash
# SpectraNet
python scripts/eval_long_horizon.py \
       --ckpt checkpoints/spectranet_ns_v1e5_canonical_best.pt \
       --data_path ./data/NavierStokes_V1e-5_N1200_T20.mat \
       --T_max 100 --label spectranet

# decorated head ablation
python scripts/eval_long_horizon.py \
       --ckpt checkpoints/spectranet_ns_v1e5_decorated_best.pt \
       --data_path ./data/NavierStokes_V1e-5_N1200_T20.mat \
       --T_max 100 --label spectranet_decorated

# FNO baseline (note: FNO blows up at T=50 — do not be alarmed by NaN in CSV)
python scripts/eval_long_horizon.py \
       --ckpt checkpoints/fno_canonical_best.pt \
       --data_path ./data/NavierStokes_V1e-5_N1200_T20.mat \
       --T_max 100 --label fno

# Transformer (rock-solid, full softmax attention)
python scripts/eval_long_horizon.py \
       --ckpt checkpoints/transformer_canonical_best.pt \
       --data_path ./data/NavierStokes_V1e-5_N1200_T20.mat \
       --T_max 100 --label transformer
```

The four runs append to `results/long_horizon.csv`; the figure is regenerated automatically after each run, or explicitly with:

```bash
python scripts/figures/make_long_horizon_figure.py
```

## Multi-seed σ (paper Table 6)

The canonical SpectraNet was trained at a single seed.  Stability evidence comes from the *decorated* variant, which was trained at seeds 0 and 1 with measured σ = 0.0001.  See `results/multi_seed.csv`.  To reproduce, retrain at `--seed 1`:

```bash
python scripts/train_spectranet.py \
       --config configs/spectranet_ns_v1e5.yaml \
       --data_root ./data --seed 1
```

## Width-scaling sweep (Appendix C, Table 9)

The width-scaling rows (w ∈ {20, 32, 48, 64} with regularization variants) are documented in `results/width_scaling.csv`.  Reproduce one row at a time by overriding `--width` and `--dropout` / `--weight_decay` on the CLI; SpectraNet was deliberately not hyperparameter-tuned for the regularization probe — see paper §6.2.

## Micro-ablation knock-out (Appendix C, Table 10)

The seven micro-experiments stacked on the residual-target baseline are recorded in `results/micro_ablation.csv`.  Each row corresponds to a single CLI flag flip; reproduce row N by adding the flag:

| Row | Flag |
|---|---|
| `M=16` | `--modes 16` |
| `M=20` | `--modes 20` |
| disk truncation | `--mode_truncation disk` |
| grouped MLP | `--mlp_groups 4` |
| spectral envelope | `--spectral_envelope` |
| `+` Semigroup-Consistency Loss | `--two_step_lambda 0.1` |
| spectral dropout | `--spectral_dropout 0.1` |

## Caveats

- The canonical 0.0822 is reported at a single seed.  The decorated-variant σ = 0.0001 across two seeds is our stability anchor; the canonical and decorated variants agree to that noise floor.
- The cross-viscosity rows confound viscosity shift with IC-distribution shift (the FNO ν=10⁻³/10⁻⁴ files were generated independently of the headline ν=10⁻⁵ release).  We treat them as a robustness probe, not a headline claim.
- The 128²→64² transfer ratio (≈ 2.01×) traces to the per-pixel head; a bilinear MLP head is not strictly bandlimited.  See paper §7.4 for the honest framing.
