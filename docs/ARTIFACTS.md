## Loading checkpoints in code

```python
import torch
from spectranet.model import SUNet2d

# canonical
m = SUNet2d(base_modes=12, width=32, in_channels=10, T_out=1,
            levels=3, ch_cap=2, output_mode="single", S=64)
sd = torch.load("checkpoints/spectranet_ns_v1e5_canonical_best.pt",
                map_location="cpu", weights_only=False)
state = sd["model"] if isinstance(sd, dict) and "model" in sd else sd
m.load_state_dict(state)
m.eval()

# decorated cross-PDE variant — set output_mode='multiscale_mlp'
m2 = SUNet2d(base_modes=12, width=32, in_channels=10, T_out=1,
             levels=3, ch_cap=2, output_mode="multiscale_mlp", S=64)
sd2 = torch.load("checkpoints/spectranet_sw_best.pt", map_location="cpu",
                 weights_only=False)
m2.load_state_dict(sd2["model"] if "model" in sd2 else sd2)
```

The eval scripts (`scripts/eval_*.py`) wrap this with `_eval_common.load_spectranet`, which auto-resolves the architecture from a sibling `*_config.json` if available.

## Hosting

The 1.5 GB `ns_v1e5_128_N1200_T20.mat` exceeds GitHub's 100 MB per-file limit, so it is hosted separately on **Zenodo** under anonymous metadata.

- **DOI**: [`10.5281/zenodo.20030455`](https://doi.org/10.5281/zenodo.20030455)
- **Direct download URL** (resolves through the DOI): https://doi.org/10.5281/zenodo.20030455
- **SHA-256** of the deposited `ns_v1e5_128_N1200_T20.mat`:
  `c0323e8dce484f6bee24a12273866a8fb9d34b78eb857ab315013518b72139a7`
- **Reproduction fallback**: the dataset is regenerable bit-identically in roughly 6 hours on a single H100 by running
  ```bash
  python scripts/generate_ns_128.py --out ./data/ns_v1e5_128_N1200_T20.mat
  ```
  The generator is deterministic given `--seed 0` (the default), so the regenerated file is bit-equivalent to the Zenodo deposit (sha256 will match).  See [`DATA.md`](DATA.md) for the protocol.

Code + the 11 pretrained checkpoints (191 MB total) are inside this anonymous repository and require no separate hosting.

## Verification

After downloading the bundle, confirm checkpoint integrity by running the smoke test:

```bash
pytest tests/test_param_count.py -v
# all six tests should pass
```

To verify a specific checkpoint loads cleanly into the package architecture:

```bash
python -c "
import torch
from spectranet.model import SUNet2d
m = SUNet2d(base_modes=12, width=32, in_channels=10, T_out=1,
            levels=3, ch_cap=2, output_mode='single', S=64)
sd = torch.load('checkpoints/spectranet_ns_v1e5_canonical_best.pt',
                map_location='cpu', weights_only=False)
res = m.load_state_dict(sd['model'] if isinstance(sd, dict) and 'model' in sd else sd)
assert not res.missing_keys and not res.unexpected_keys
print('OK: 0 missing, 0 unexpected keys')
"
```
