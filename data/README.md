# Datasets shipped in this directory

This directory holds **only the datasets we generated ourselves**.  Public datasets (FNO ν=10⁻⁵/10⁻⁴/10⁻³, PDEBench Shallow Water + Diffusion-Reaction, The Well Active Matter) must be downloaded separately — see [`../docs/DATA.md`](../docs/DATA.md).

## Files

| Filename | Bytes | Provenance |
|---|---:|---|
| `ns_v1e5_128_N1200_T20.mat` | ~1.5 GB | Generated by `scripts/generate_ns_128.py` from a fixed seed.  See `docs/DATA.md` for the protocol details (Li et al. 2020 vorticity-form pseudo-spectral solver, 2/3 dealiasing, Crank–Nicolson on viscous part, explicit Euler on advection). |

## Layout contract

Every `.mat` consumed by the trainers contains a single field `u` of shape `(N_traj, S, S, T)` (real, fp32).  `MatReader` (`spectranet/data.py`) handles both scipy v5 (small files) and HDF5 v7.3 (large files) transparently.
